# 马头琴文化资源数据库资料来源、版权与内容审核规范

- 版本：1.0
- 制定日期：2026-08-19
- 对应路线：第6步“制定来源、版权和审核规范”

## 1. 适用范围

本规范适用于数据库记录、图片、音频、视频、三维模型、文档、访谈、田野资料和网页文字。来源判断、版权判断和内容审核分别记录，不能以“来源可靠”代替“可以公开”，也不能以“可以公开”代替“内容已经核实”。

## 2. 来源登记字段

每项来源至少记录：

| 字段 | 要求 |
| --- | --- |
| 来源编号 | 按 `MK-R-###` 管理 |
| 来源类型 | 文献、档案、名录、馆藏记录、访谈、田野调查、机构网页、新闻媒体、公开网络或其他 |
| 原始题名 | 按原来源著录，不擅自改写 |
| 作者或责任者 | 缺失时保留空值 |
| 出版者、收藏者或持有机构 | 缺失时保留空值 |
| 出版或形成日期 | 保存原始表述和日期精度 |
| 标识符 | ISBN、DOI、档号、馆藏号或其他 |
| URL与访问日期 | 适用于网络来源 |
| 采集时间和地点 | 适用于访谈、田野和自采媒体 |
| 采集者、拍摄者或录音者 | 缺失时保留空值 |
| 提供者 | 与作者、权利人分开记录 |
| 关联记录 | 来源支持的资源编号和字段 |
| 可信度等级 | 按第4节记录 |
| 核实说明 | 交叉来源、矛盾点和待核实事项 |
| 推荐引用格式 | 可直接用于记录详情页 |

转载页面不是原始出处时，应继续追溯原始来源；无法追溯时明确标记“原始出处待核实”。

## 3. 来源类型与证据使用

- 正式出版物、档案和权威名录按原文著录，不把摘要或二手转述当成原文。
- 博物馆、文化机构和研究机构资料需记录机构、页面或馆藏编号及访问日期。
- 访谈和田野资料需记录知情同意、公开范围、受访者身份呈现方式和采集条件。
- 传承人口述可作为重要来源，但口述内容、研究者解释和其他文献证据必须区分。
- 新闻和网络内容可作为线索或辅助证据，不自动升级为已确认事实。
- 同一事实存在冲突时并列记录观点和来源，不自行消除争议。

## 4. 资料可信度等级

| 等级 | 来源范围 | 使用要求 |
| --- | --- | --- |
| 一级 | 国家级名录、档案、正式出版文献 | 核对版本、页码、档号或稳定标识符 |
| 二级 | 博物馆、文化机构、专业研究成果 | 记录机构和具体出处 |
| 三级 | 田野调查、正式访谈、传承人口述 | 记录采集方法、时间、授权和语境 |
| 四级 | 新闻媒体和公开网络资料 | 尽量交叉核实，不单独支持高争议结论 |
| 五级 | 来源待核实 | 仅用于内部整理或明确标示待核实内容 |

可信度等级评价的是具体来源，不是对作者、机构或人物的永久评价。同一记录可关联不同等级来源。

## 5. 版权状态

| 状态 | 含义 | 默认公开处理 |
| --- | --- | --- |
| 自有资料 | 项目方拥有相应权利且有记录证明 | 按项目许可和授权范围公开 |
| 已获授权 | 权利人已明确授权 | 严格按照授权期限、范围和署名方式公开 |
| 公共领域 | 经核实不受版权保护或保护期届满 | 保留来源和公共领域判断依据 |
| 合理引用 | 在研究、评论或说明所需限度内引用 | 只展示必要部分，完整标注出处，不提供无依据下载 |
| 仅供研究 | 可在限定研究环境使用 | 不公开原文件，按申请或内部访问管理 |
| 版权待确认 | 权利人、许可或期限尚未核实 | 默认暂不公开媒体原件 |
| 禁止公开 | 明确不得公开或授权已拒绝 | 不在公开网站展示或下载 |

版权状态必须针对具体对象和具体权利判断。实物进入公共领域不代表其现代摄影、录音、文字说明或数字模型自动进入公共领域。

本规范用于项目内部管理，不替代专业法律意见；遇到权属争议、敏感资料或跨境使用时应另行咨询。

## 6. 公开级别

| 公开级别 | 允许范围 |
| --- | --- |
| 完全开放 | 可浏览并按明确许可下载或再利用 |
| 仅展示 | 可在网站查看，不提供原始文件下载 |
| 申请使用 | 页面可显示基本信息，文件需申请和审批 |
| 研究者可访问 | 仅向符合条件的研究者提供受控访问 |
| 暂不公开 | 不在公开网站呈现，保留内部记录 |

公开级别由版权、隐私、文化敏感性、授权条件和保存需要共同决定。不得仅因文件已经上传到仓库就认定为“完全开放”。

## 7. 内容审核状态

| 状态 | 定义 | 可执行操作 |
| --- | --- | --- |
| 待整理 | 尚未完成最小字段和来源登记 | 仅内部盘点 |
| 已著录 | 已按模板录入，但未完成核实 | 内部校对 |
| 待核实 | 存在来源、年代、名称、关系或权利疑问 | 显式列出问题并补证 |
| 专家确认 | 关键内容经适当领域专家或责任审核人确认 | 进入发布检查 |
| 公开发布 | 字段、来源、权利和展示范围均通过检查 | 可在公开页面呈现 |

状态按实际流程推进，不得为满足进度批量改成“专家确认”或“公开发布”。修改关键事实或新增媒体后，应退回相应审核状态重新检查。

## 8. 审核角色与职责

- 著录者：录入原始信息、来源和空值，不补写推测。
- 校对者：检查字段格式、编号、链接、引文和媒体对应关系。
- 内容审核者：核对事实、术语、年代、人物关系和证据充分性。
- 权利审核者：核对权利人、授权、署名、期限、地区和公开级别。
- 发布责任人：确认页面只显示允许公开的内容并记录发布版本。

同一人可承担多个角色，但每次审核仍需留下日期、结果和说明。

## 9. 发布检查规则

记录公开前必须满足：

1. 具有唯一编号、中文名称、资源类型、摘要和更新时间；
2. 至少一项可追溯来源支持核心事实；
3. 年代、人物关系、机构归属和蒙古文信息没有无来源补写；
4. 版权状态和公开级别已经确定；
5. 每个公开媒体具有创作者或来源、权利状态、署名方式和展示范围；
6. 涉及访谈、未成年人、在世人物或敏感文化信息时已核对同意和隐私要求；
7. 记录状态达到“公开发布”，并保留审核日期和责任记录；
8. 推荐引用格式可生成，记录编号和版本可追踪。

若核心事实仍待核实，可保留内部记录；确需公开展示争议时，必须明确标注“待核实”及其依据，不能以确定语气发布。

## 10. 媒体处理决策

| 条件 | 处理方式 |
| --- | --- |
| 自有或已授权，且授权范围覆盖网站展示 | 按授权署名并公开 |
| 已核实公共领域 | 记录判断依据后公开 |
| 合理引用 | 限量、低风险展示并完整注明出处 |
| 仅供研究 | 不公开原文件，提供申请说明 |
| 版权待确认 | 默认不公开；可使用明确标记的占位信息 |
| 禁止公开 | 不上传公开目录，不生成公开链接 |
| 来源不明 | 进入待核实清单，不推测作者或权利人 |

## 11. 更正、撤回与版本记录

- 发现错误时记录原值、修改值、原因、来源、修改人和日期。
- 版权或隐私投诉优先暂停公开访问，再核查权属和事实。
- 撤回记录保留编号、最小元数据和撤回说明，避免编号被复用。
- 公开页面应显示记录更新时间和数据库版本；重大更正保留变更说明。
- 来源网页失效时保留访问日期和已保存的书目信息，不虚构替代链接。

## 12. 推荐引用模板

```text
《{记录中文名称}》，马头琴文化资源数据库，
记录编号：{record_id}，版本：{record_version}，
访问日期：{access_date}，网址：{record_url}。
```

作者、编者或机构信息只有在项目正式确认后才加入模板。

## 13. 完成判定

- 来源登记字段和追溯规则明确；
- 五级可信度标准明确；
- 七种版权状态和五种公开级别明确；
- 五阶段审核状态、角色和发布检查明确；
- 待核实、版权待确认、禁止公开和敏感资料均有处理规则；
- 未对现有资料作任何虚构的来源或版权判断。
