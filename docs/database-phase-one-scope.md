# 马头琴文化资源数据库首期收录范围与分类目录

- 文件版本：1.0
- 制定日期：2026-08-18
- 适用阶段：数据库建设首期
- 对应路线：第2步“确定首期收录范围”
- 工作分支：`database-rebuild`

## 一、建设边界

首期建设以现有数字展览中的资源盘点、规范著录和结构化转换为核心，不以新增大量内容为目标。现有网页中的文字、图片、音频和可视化内容，只有在能够作为独立资源辨识和著录时，才进入数据库记录。

首期数据层设九个一级资源类型：器物、部件、制作技艺、制作材料与工具、传承人物、音乐与曲目、装饰纹样、历史事件、文化场景。

首期不建设用户注册、公众上传、在线评论、复杂权限管理、大规模视频存储、人工智能问答和商业交易功能。是否建设后台数据库留待数据规模和协作需求达到路线规定的条件后再评估。

## 二、通用收录原则

一项资源进入首期数据库，至少应满足以下条件：

1. 能够明确区分为一件器物、一个部件、一道技艺、一种材料或工具、一位人物、一项音乐资源、一种纹样、一个历史事件或一个文化场景；
2. 与马头琴文化直接相关，而不是仅作为页面装饰的通用素材；
3. 至少能够记录中文名称或临时工作名称、资源类型、内容说明和审核状态；
4. 资料来源和版权信息可以暂缺，但必须保留空值或标记为“待核实”“版权待确认”，不得推测；
5. 同一资源的多张图片、多个音频或不同版本作为关联媒体或版本记录管理，原则上不重复建立完全相同的主体记录。

以下内容首期不作为已确认知识直接发布：

- 无法辨识对象、与马头琴关系不明确的素材；
- 没有出处且无法交叉核实的具体年代、人物关系、机构归属或历史结论；
- 未经核实的蒙古文名称、转写和译名；
- 版权状态不明却被标记为可下载或可再利用的媒体；
- 仅用于界面背景、按钮或装饰且没有独立研究价值的视觉素材。

## 三、首期收录范围表

| 一级类型 | 收录对象 | 首期主要来源 | 暂不处理或需谨慎处理 |
| --- | --- | --- | --- |
| 器物 | 可作为完整马头琴或器物样本辨识的对象及其整体记录 | 现有器物样本、器型展示、已有整琴图片 | 不依据外观推测年代、产地、作者、收藏机构或真伪 |
| 部件 | 琴首、琴杆、琴轴、琴弦、琴码、琴箱、面板、背板、弓等可独立说明的构成部分 | 现有结构与构造展示 | 仅有示意图而无实物依据时，应标明“示意”或“待核实” |
| 制作技艺 | 可独立描述的材料处理、部件制作、装配、装饰和调试工序 | 现有制作工艺章节 | 不把缺乏来源的操作描述标记为唯一或标准工艺 |
| 制作材料与工具 | 制作所用木材、膜皮、弦材、装饰材料、辅助材料及手工、电动、测量工具 | 现有材料与工具展示 | 不推测材料物种、产地、规格和传统使用年代 |
| 传承人物 | 与制作、演奏、教学、研究、收藏或传播相关且可独立著录的人物 | 现有人物与传承内容 | 出生年代、身份称号、师承关系和名录级别必须有来源 |
| 音乐与曲目 | 曲目、演奏版本、音频、乐谱及相关说明 | 现有音乐分类与音高示范 | 曲名、作者、地区归属、体裁和版权未经核实不得确定 |
| 装饰纹样 | 可辨识并可独立说明的几何、植物、动物、文字或复合纹样 | 现有纹样章节 | 不仅凭形状推测名称、族属、象征含义或年代 |
| 历史事件 | 与马头琴发展、传播、制度、展演或研究有关且有时间关系的事件 | 现有历史脉络页面 | 时间、因果关系和历史评价必须区分事实、观点与待核实内容 |
| 文化场景 | 制作、演奏、教学、礼俗、节庆、展示和当代应用等情境记录 | 现有应用场景和文化生态内容 | 不根据图片自行推测地点、人物、活动名称和拍摄时间 |

本文件不制定编号规则，也不为任何实际资源分配编号；编号工作留到路线第5步。

## 四、一级、二级分类目录

二级分类用于首期盘点和著录，可在第7步根据现有资源数量提出增删建议。一个资源主体只设一个主要一级类型；跨类型联系以后通过关联字段表达。

### 1. 器物

- 完整器物
- 器物样本与复制品
- 器型与形制记录
- 器物影像记录
- 待分类器物

### 2. 部件

- 琴首与装饰构件
- 琴杆与指板相关构件
- 琴轴、琴弦与调弦构件
- 琴码
- 琴箱
- 面板与背板
- 琴弓
- 其他或待分类部件

### 3. 制作技艺

- 选材与材料预处理
- 琴箱制作
- 琴杆与琴首制作
- 面板、背板与蒙面处理
- 琴轴、琴码与琴弓制作
- 装配与粘接
- 雕刻、彩绘与表面处理
- 装弦、调试与修整
- 维护与修复
- 待分类工序

### 4. 制作材料与工具

- 木材
- 膜皮与蒙面材料
- 琴弦与弓毛材料
- 胶合、涂饰与装饰材料
- 其他辅助材料
- 切削与雕刻工具
- 测量与定位工具
- 夹持、装配与修整工具
- 电动工具
- 模具与辅助装置
- 待分类材料或工具

### 5. 传承人物

- 制作技艺相关人物
- 演奏与表演相关人物
- 教学与传习相关人物
- 研究、整理与记录相关人物
- 收藏、保护与传播相关人物
- 多重角色人物
- 待核实人物

人物分类描述其在数据库记录中的主要关联角色，不替代正式身份、职称、名录级别或师承认定。

### 6. 音乐与曲目

- 曲目记录
- 演奏版本记录
- 音频记录
- 乐谱记录
- 教学与音高示范
- 音乐分类说明
- 待分类音乐资源

### 7. 装饰纹样

- 几何纹样
- 植物纹样
- 动物纹样
- 文字与符号纹样
- 复合纹样
- 纹样应用实例
- 名称或含义待核实纹样

### 8. 历史事件

- 起源与早期记载相关事件
- 器型与制作技术变化事件
- 人物与传承相关事件
- 展演、传播与交流事件
- 保护政策、名录与机构事件
- 研究、出版与收藏事件
- 时间或性质待核实事件

### 9. 文化场景

- 制作场景
- 日常演奏场景
- 舞台与公共展演场景
- 教学与传习场景
- 礼俗、节庆与仪式场景
- 收藏、博物馆与展览场景
- 当代设计与应用场景
- 地点或活动待核实场景

## 五、资源粒度与交叉关系

- 完整器物与其部件分别著录，通过“由……构成”关系连接；
- 制作技艺与所用材料、工具分别著录，通过“使用”关系连接；
- 人物记录与其相关器物、技艺、曲目和场景连接，不把全部信息重复写入人物简介；
- 曲目主体、演奏版本和音频媒体分层管理，避免把音频文件等同于曲目本身；
- 历史事件记录事实与来源，专题页面可在以后引用事件记录形成叙事；
- 同一图片可关联多个记录，但必须保留媒体自身的来源和版权状态。

关联字段的正式结构留到第14步制定，本步骤只确定分类边界。

## 六、首期与后续阶段的界线

首期目标是完成规范、盘点、结构化数据和基本浏览检索。以下功能后置：

| 后置内容 | 后置原因或条件 |
| --- | --- |
| 用户注册、评论和公众上传 | 需要权限、审核、隐私和安全机制 |
| 多人在线录入与复杂后台 | 数据量或协作需求达到路线中的升级条件后评估 |
| 大规模高清音视频托管 | 需要版权、带宽、存储和长期保存方案 |
| 人工智能问答 | 需先建立可信、可引用的数据基础 |
| 商业交易 | 不属于当前学术型文化资源数据库目标 |
| 完整蒙古文检索与界面 | 待蒙古文资料、转写规范和审核机制具备后建设 |

## 七、执行约束

- 第7步盘点现有内容时，按本目录归类，但不得为了填满分类而编造记录；
- 某项资源暂时无法归类时，进入相应“待分类”项并记录原因；
- 年代、来源、版权、蒙古文名称和人物关系缺失时保留空值或待核实状态；
- 分类调整必须留下版本记录，不覆盖原始资料；
- 第3步的信息架构可将九类数据入口组合展示，但不得删除数据层的一级类型。

## 八、完成判定

本步骤在以下条件全部满足时完成：

- 九类首期资源均有明确的收录对象和不推测规则；
- 暂缓功能边界已经列明；
- 一级、二级分类目录覆盖九类资源；
- 资源粒度和交叉关系原则已经说明；
- 未为任何具体资源推测年代、来源、版权或蒙古文信息；
- 文件保存在数据库改造工作分支，原始展示版文件未改动。
